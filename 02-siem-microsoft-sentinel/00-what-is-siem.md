# What is a SIEM?

## Definition
SIEM stands for Security Information and Event Management. It is a centralized 
system that SOC Analysts use to monitor, detect, and respond to security threats 
across an organization's systems in real time.

## Why it matters
Without a SIEM, a SOC Analyst would have to manually check dozens of different 
systems one by one to gather information — which is slow, unrealistic at scale, 
and makes it easy to miss real threats. A SIEM solves this by pulling everything 
into one place so threats can be spotted quickly.

## Key functions
- **Collects:** Gathers data and system logs from various sources
- **Correlates:** Combines related events together for easier analysis
- **Alerts:** Sends an alert when a threat is detected in the system
- **Stores:** Stores historical data for future investigation and reporting

## What makes Microsoft Sentinel different
Microsoft Sentinel is a cloud-native SIEM, meaning it runs entirely in Azure 
rather than on physical, on-premises servers. It also includes SOAR (Security 
Orchestration, Automation, and Response) capabilities — so beyond just detecting 
threats, it can help automate parts of the response too.

## My takeaway
SIEM helps me, as a SOC Analyst, focus on and monitor real-time security threats — 
and respond to them as they happen, instead of chasing information across 
scattered systems.
